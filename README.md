Sky Courier — Coral Isles Mail Run: fly the little seaplane Kestrel across six islands. Take off from Palmquay, thread five golden rings, drop mail parcels onto the red zones, and bring her home to land at Home Strip before the fuel — or the clock — runs out. Canvas 2D art drawn in code, WebAudio-synthesised engine and effects, no libraries, no network.

## Run it

```sh
python3 -m http.server --directory game
# then open http://localhost:8000 in desktop Chrome
```

Controls: ↑/W climb, ↓/S descend, →/D throttle up, ←/A throttle down, Space or click to drop mail, P pause, M mute, Enter start, R restart.
